# Malaysia COVID-19 Impact Analysis Dashboard 🇲🇾

A comprehensive data visualization project built with Microsoft Power BI to analyze the spread, mortality, healthcare impact, and vaccination response of the COVID-19 pandemic across Malaysia. 

## 📊 Dashboard Overview
The main dashboard tracks critical top-line metrics including Total Cases (5M+), Active Cases (45K), and Total Deaths (36K), alongside geospatial mapping and ICU utilization rates.

## 🔍 Deep Dive Analytics

### 1. Epidemic Analysis
Tracks outbreak sources, revealing that Workplace clusters drove the highest number of cases, followed by Community and Education clusters. Features an interactive decomposition tree for tracing specific cluster outbreaks by state.

<img width="1321" height="752" alt="Epidemic Analysis" src="https://github.com/user-attachments/assets/2b717f80-0d6a-4007-8c0b-d9a843cfa895" />


### 2. Mortality Analysis
Monitors healthcare capacity and fatality metrics, including a 0.76% Case Fatality Rate (CFR) and a breakdown of Brought-In-Dead (BID) vs. In-Hospital deaths against daily ventilated patients.

<img width="1306" height="739" alt="Mortality Analysis" src="https://github.com/user-attachments/assets/302490b5-3655-45d7-a314-3e1b53cd73c9" />


### 3. Response & Effectiveness Analysis
Evaluates the national vaccination rollout, tracking cumulative doses, positivity rates, and the correlation between being fully vaccinated and total deaths at the state level.

## 🛠️ Tools & Technologies Used
* **Business Intelligence:** Microsoft Power BI
* **Data Processing:** Power Query
* **Calculations & Logic:** DAX (Data Analysis Expressions)
* **Visualizations:** Geospatial maps, decomposition trees, donut charts, gauge charts, and time-series plots.
